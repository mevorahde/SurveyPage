# Survey Page

This repository preserves a survey-form exercise completed for freeCodeCamp's
Responsive Web Design curriculum in 2018. It demonstrates an early static HTML
and CSS form with common input, select, radio, checkbox, and textarea controls.

## View locally

Clone or download the repository and open `index.html` in a browser. The form
is a front-end learning exercise: it has no backend, does not submit or store
responses, and should not be used to collect personal information.

## Status

The project is retained as a historical learning artifact and is not actively
maintained. It does not represent my current accessibility, validation, or
production-development standards.
